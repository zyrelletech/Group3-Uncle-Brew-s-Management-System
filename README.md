# Group3-Uncle-Brew-s-Management-System


Uncle Brew's Management System
This project is a Management System for Uncle Brew's coffee shop, developed as part of our Information Management course. The system is designed to efficiently manage customer orders, inventory, and sales reporting, ensuring fast and accurate service for both admins and cashiers.

Purpose
The main goal of this system is to:
Speed up the customer ordering process. Automatically track and deduct ingredients in real-time. Manage user access for Admin and Cashier roles. Monitor sales and generate daily, weekly, and monthly revenue reports. Replace manual paper-based inventory with a digital tracking system.
Features Product and Ingredient Management (Add, Edit, Delete) Order Processing with Drink Customization Shift Management for Cashiers Sales and Reporting Dashboard Low-Stock Alerts and Performance Analytics Simple and clean user interface
